Topic 16 Murphy, PML — §18.5.1 – 18.5.4 Boosting

Many weak learners, added one at a time

Boosting builds a strong model as a sum f(x) = Σm βm Fm(x) of weak ones. Here every Fm is a stump: a tree with a single split. Each round adds one new term aimed at what the current sum still gets wrong. Least squares boosting, AdaBoost and LogitBoost all follow the same recipe; they differ only in the loss, and the loss decides what "still gets wrong" means.

① The recipe (§18.5.1) ② Squared loss → residuals (§18.5.2) ③ Exponential loss → AdaBoost (§18.5.3) ④ Log loss → LogitBoost (§18.5.4)
①

The recipe: forward stagewise additive modelling

Step 0 · start simple
f0(x) = argminγ Σi ℓ(yi, γ)

The best constant. For squared loss that is the mean ȳ; for the two classification losses below it is 0 when the classes are balanced ("no idea yet").

Step 1 · fit one new term
(βm, θm) = argminβ, θ Σi ℓ(yi, fm−1(xi) + β F(xi; θ))

Search only over the new learner F (its split θ) and its size β. Everything already in the model stays frozen.

Step 2 · add it and repeat
fm(x) = fm−1(x) + βm F(x; θm)

Then go back to step 1 for round m + 1. Optional shrinkage: add ν βm Fm with 0 < ν ≤ 1 to take smaller steps.

"Stagewise" means old terms are never refit. Each round solves one small problem (pick one stump) instead of one huge joint problem (pick all M stumps at once). Step 1 is the only part that depends on the loss, and for each common loss it turns into something familiar:

Lossℓ(y, f)Step 1 becomes…Walkthrough
Squared(y − f)²fit F to the residuals r = y − f② least squares boosting
Exponentialexp(−ỹ f)fit F to reweighted data, ωi ∝ exp(−ỹi f(xi))③ AdaBoost
Log losslog(1 + e−2ỹf)fit F by weighted least squares to "working responses" z (a Newton step)④ LogitBoost

Notation: for classification the labels are ỹ ∈ {−1, +1}, and y* = (ỹ + 1)/2 ∈ {0, 1} is the same label written as 0/1. The product ỹ f(x) is the margin: positive means the point is on the right side, and bigger means more confident.

Where did β go?

For squared loss the stump's two leaf values are already the best amounts to add (the mean residual on each side), so β can be folded into F and set to 1. Only ν, if you use shrinkage, scales the step.

Where do errm and βm come from?

Plug exponential loss into step 1 of the recipe: Σi exp(−ỹi(fm−1(xi) + βF(xi))) = Σi ωi exp(−β ỹi F(xi)) with ωi = exp(−ỹi fm−1(xi)). Since ỹF is +1 for a hit and −1 for a miss, this is (eβ − e−β) Σi ωi I(ỹi ≠ F(xi)) + e−β Σi ωi. The first term says: pick F with the smallest weighted error. Setting the derivative in β to 0 then gives β = ½ log((1 − err)/err).

Murphy's β vs. the α in AdaBoost.M1

The classic algorithm uses αm = log((1 − errm)/errm) = 2βm and multiplies only the misses by eα. After normalising, the weights are the same as here, and sign(Σ αm Fm) = sign(Σ βm Fm), so it is the same classifier.

Log loss: LogitBoost takes Newton steps

Exponential loss blows up for badly misclassified points, so a single outlier can dominate AdaBoost. LogitBoost swaps in log loss, the loss of logistic regression. First see why, then walk through a round.

Why is the Newton step a weighted least squares fit?

Expand the log loss around the current f to second order. At each point the slope is gi ∝ πi − y*i and the curvature is hi ∝ πi(1 − πi) = wi. A quadratic Σi (gi Fi + ½ hi Fi²) is, up to a constant, ½ Σi wi(zi − Fi)² with zi = −gi/hi = (y*i − πi)/wi. So minimising the local approximation is exactly a weighted least squares fit of F to z. The ½ in step 4 undoes the 2 in π = σ(2f).

Why clip z?

When π is very close to 0 or 1, w = π(1 − π) is tiny and z = (y* − π)/w can be huge for a point on the wrong side. Its weight is tiny too, so in exact arithmetic it barely matters, but numerically it is safer to cap z (here at ±4, a common choice).

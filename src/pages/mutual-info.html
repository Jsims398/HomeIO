Topic 7 Murphy, PML — §6.3 Mutual information

How much does Y tell you about X?

Mutual information is the number of bits you learn about X by seeing Y.

6.3

Key points

Definition
I(X;Y) = KL(p(x,y) ‖ p(x)p(y))

How far the real joint is from what it would be if X and Y were independent.

Interpretation
I(X;Y) = H(X) − H(X|Y)

Your uncertainty about X before seeing Y, minus what's left after. Symmetric: swap X and Y and you get the same number.

Zero means independent
I(X;Y) ≥ 0

It equals 0 only when X and Y are independent. Correlation doesn't have this property: ρ = 0 can still hide strong dependence.

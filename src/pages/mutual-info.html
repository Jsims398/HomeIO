Topic 7 Murphy, PML — §6.3 Mutual information

How much does Y tell you about X?

Mutual information is the number of bits you learn about X by seeing Y.

6.3

Key points

Definition
I(X;Y) = KL(p(x,y) ‖ p(x)p(y))

How far the real joint is from what it would be if X and Y were independent.

Interpretation
I(X;Y) = H(X) − H(X|Y)

Your uncertainty about X before seeing Y, minus what's left after. Symmetric: swap X and Y and you get the same number.

Zero means independent
I(X;Y) ≥ 0

It equals 0 only when X and Y are independent. Correlation doesn't have this property: ρ = 0 can still hide strong dependence.

Exam notes · 4-point version

MI three ways on 4 observations

Data (x, y): (0, 0) (0, 0) (1, 0) (1, 1). All logs base 2, so answers are in bits.

  1. Joint table (count ÷ 4): p(0,0) = 2/4 = 0.5 p(1,0) = 0.25 p(1,1) = 0.25 p(0,1) = 0
  2. Marginals. p(x) = (0.5, 0.5), p(y) = (0.75, 0.25)
  3. Way 1, definition I = Σ p(x,y) log₂ [p(x,y) / (p(x)p(y))]: 0.5·log₂(0.5/0.375) = 0.208 + 0.25·log₂(0.25/0.375) = −0.146 + 0.25·log₂(0.25/0.125) = 0.25 → I = 0.311 bits
  4. Way 2, H(X) − H(X|Y). H(X) = 1 bit (fair coin). Given y = 0 (prob 0.75), x is 0 two times out of 3: H(2/3, 1/3) = 0.918. Given y = 1, x = 1 for sure: H = 0. So H(X|Y) = 0.75·0.918 + 0.25·0 = 0.689 → I = 1 − 0.689 = 0.311 ✓
  5. Way 3, symmetric: H(Y) − H(Y|X). H(Y) = H(0.75, 0.25) = 0.811. Given x = 0, y = 0 for sure (0 bits). Given x = 1, y is a fair coin (1 bit). H(Y|X) = 0.5·0 + 0.5·1 = 0.5 → I = 0.811 − 0.5 = 0.311 ✓
  6. Check ≥ 0. 0.311 > 0, so X and Y are dependent: knowing y = 1 tells you x = 1.

Say it in one sentence: mutual information is the KL divergence between the real joint and the product of the marginals, which equals how many bits of uncertainty about X you lose by seeing Y (and vice versa); it is 0 only when the variables are independent.

Exam notes · 4-point version

Same marginals, two different joints

Two data sets of 4 coin pairs (x, y). Both have p(x) = p(y) = (0.5, 0.5), so the "if independent" table is p(x)p(y) = 0.25 in every cell for both.

Case A: independent

  1. Data: (0,0) (0,1) (1,0) (1,1), so the joint is 0.25 in every cell.
  2. Compare with the product table: identical. Every term is 0.25·log₂(0.25/0.25) = 0 → I = 0 bits.

Case B: perfectly dependent

  1. Data: (0,0) (0,0) (1,1) (1,1), so the joint is p(0,0) = p(1,1) = 0.5, off-diagonal 0.
  2. Product table still says 0.25 everywhere. Terms: 0.5·log₂(0.5/0.25) = 0.5 twice, zeros contribute 0 → I = 1 bit.
  3. Check: H(X) − H(X|Y) = 1 − 0 = 1. Seeing y tells you x completely, which removes all 1 bit of uncertainty.

Say it in one sentence: build the table independence would predict (multiply the marginals) and compare it with the real joint; if they match, MI is 0, and the further apart they are, the more bits Y tells you about X.

Exam notes · 4-point version

ρ = 0 but MI = 1 bit

Parabola: (−2, 4) (−1, 1) (1, 1) (2, 4), so y = x². Each point has probability 1/4.

  1. Correlation. Means: x̄ = 0, ȳ = 2.5. Covariance Σ (x − x̄)(y − ȳ) = (−2)(1.5) + (−1)(−1.5) + (1)(−1.5) + (2)(1.5) = 0 → ρ = 0. The left half cancels the right half.
  2. Entropies. x takes 4 equally likely values: H(X) = log₂ 4 = 2 bits. y takes 2 (1 or 4), each half the time: H(Y) = 1 bit.
  3. Conditional. Knowing y leaves only the sign of x unknown (2 options): H(X|Y) = 1 bit. Knowing x gives y exactly: H(Y|X) = 0.
  4. MI. I = H(X) − H(X|Y) = 2 − 1 = 1 bit (also H(Y) − H(Y|X) = 1 − 0 = 1). Strong dependence that correlation misses completely.
  5. Contrast, a straight line (−2,−2) (−1,−1) (1,1) (2,2): ρ = 1, and y pins down x exactly, so I = H(X) = 2 bits.
  6. On the page's 0–1 scale, R = √(1 − 2^(−2I)); for I = 1, R = √(1 − 1/4) = 0.87 (exact match to |ρ| only for Gaussians).

Say it in one sentence: correlation measures only how well a straight line fits, so a symmetric curve can have ρ = 0, while MI measures any kind of dependence and is 0 only when the variables are truly independent.

Topic 13 Murphy, PML — §17.3.4 Support vector machines

Curved boundaries from straight lines

An SVM draws a straight line (a flat boundary) between two classes. Lots of data can't be split by a straight line. The fix has two steps. First, lift each point into more dimensions with a feature map φ(x), where a flat cut does work. Second, the trick: the SVM only ever needs dot products φ(a)·φ(b), and a kernel K(a, b) gives you that number straight from a and b. You never build φ at all.

①

Why lift: tangled in 1-D, easy in 2-D

Big idea
Add a new coordinate that untangles the classes

On a number line, a linear classifier is a single cut: everything right of it is one class. If one class sits in the middle, no cut works. But give each point a second coordinate x², and the middle points stay low while the outer ones go high. Now a flat line separates them.

Formula, decoded
φ(x) = (x, x²)

φ (phi) is the feature map: a recipe that turns each input into a longer list of numbers. The classifier is still linear, just in φ-space: "is x² below t?" Back on the original line, that one flat rule becomes two cuts at x = ±√t.

So why not always lift?

Here φ added one number. Real data might have 1,000 inputs, and using all their pairwise products means about 500,000 new features; triples, about 167 million. Building and storing φ for every point gets hopeless. That cost is what the trick removes.

②

The trick: get φ(a)·φ(b) without building φ

Why it works for SVMs
The SVM only asks "how much do these two points agree?"

In the dual form of the SVM (§17.3.2), training and prediction use the inputs only through dot products xᵢ·xⱼ. Never a single coordinate on its own. So if we lift, all we need is φ(xᵢ)·φ(xⱼ), one number per pair.

Formula, decoded
K(a, b) = φ(a)·φ(b)

A kernel is a function that hands you that dot product directly. Example in 2-D: φ(x) = (x₁², √2 x₁x₂, x₂²) has the kernel K(a, b) = (a·b)². Lift-then-dot needs 3 features; the kernel needs one 2-D dot product and a square. Below, check that they give the same number.

What about the RBF kernel?

K(a, b) = exp(−γ‖a − b‖²) is 1 when a = b and fades to 0 as they move apart. Its φ has infinitely many features, so the long way is impossible, yet the short way is one subtraction and one exp(). That is the trick at its most extreme.

Can any function be a kernel?

No. K has to equal φ(a)·φ(b) for some φ, even one you never write down. Those are called Mercer (positive definite) kernels: every Gram matrix [K(xᵢ, xⱼ)] they produce has no negative eigenvalues. Linear, polynomial and RBF all qualify.

③

Lab: one SVM, three kernels

Formula, decoded · the prediction
f(x) = Σn αn yn K(xn, x) + w₀

Swap every x·x′ in the SVM for K(x, x′). To classify a new x, compare it with each training point using K, weight by αn (learned) and the label yn = ±1, and add them up. Positive → class +.

The book calls it
Support vectors

Most αn come out exactly 0, so most points drop out of the sum. The ones left (ringed below) are the support vectors: the points on or inside the margin. The prediction only needs K between x and those few points.

How did the SVM learn α without φ?

The dual training problem is: maximise Σαn − ½ ΣΣ αiαj yiyj K(xi, xj) with 0 ≤ αn ≤ C and Σαnyn = 0. The data shows up only in the N × N table of K values (the Gram matrix). This page fills that table, then solves for α with SMO, a standard solver that updates two α's at a time.

PCA, one step at a time

Principal components analysis finds the L directions w1, …, wL along which the data varies most, and describes each point x by its coordinates z = Wᵀ(x − μ) along them. Three walkthroughs, each with numbers small enough to check by hand: ① do PCA on six points, ② the practical issues in computing it, ③ how to pick L.

PCA on 4 points, fully by hand

Data: x₁ = (2, 4) x₂ = (4, 2) x₃ = (6, 8) x₄ = (8, 6). Goal: one number per point.

  1. Mean. μ = ((2+4+6+8)/4, (4+2+8+6)/4) = (5, 5)
  2. Center. Subtract μ: x̃ = (−3, −1), (−1, −3), (1, 3), (3, 1)
  3. Covariance Σ = (1/N) Σ x̃ x̃ᵀ: Σ₁₁ = (9+1+1+9)/4 = 5, Σ₂₂ = (1+9+9+1)/4 = 5, Σ₁₂ = (3+3+3+3)/4 = 3, so Σ = [5 3 ; 3 5]
  4. Eigenvalues. det(Σ − λI) = (5 − λ)² − 3² = 0 → 5 − λ = ±3 → λ₁ = 8, λ₂ = 2
  5. Eigenvectors. λ₁ = 8: (5−8)w_x + 3w_y = 0 → w_x = w_y → w₁ = (1, 1)/√2 ≈ (0.71, 0.71). λ₂ = 2: 3w_x + 3w_y = 0 → w₂ = (1, −1)/√2. Always divide by the length so ‖w‖ = 1.
  6. Encode. z = w₁ᵀ x̃: (−3 − 1)/√2 = −2.83, so z = −2.83, −2.83, 2.83, 2.83
  7. Decode. x̂ = μ + z w₁: −2.83 · (0.71, 0.71) = (−2, −2), so x̂ = (3, 3), (3, 3), (7, 7), (7, 7)
  8. Error. ‖x₁ − x̂₁‖² = (2−3)² + (4−3)² = 2, and the same for every point, so mean error = 2 = λ₂. Variance kept: mean z² = 8 = λ₁. Check: 8 + 2 = 10 = trace Σ = 5 + 5.

Say it in one sentence: center the data, take the eigenvectors of the covariance, keep the ones with the biggest eigenvalues; each direction you drop costs exactly its eigenvalue in squared reconstruction error.

Exam notes · 4-point versions

Three practical issues, each on 4 points

(a) Units: why you standardize

  1. Same 4 points as ①, but measure x₁ in mm instead of cm (×10): x̃₁ = (−30, −10, 10, 30), x̃₂ unchanged (−1, −3, 3, 1).
  2. Covariance: Σ₁₁ = (900+100+100+900)/4 = 500, Σ₁₂ = (30+30+30+30)/4 = 30, Σ₂₂ = 5 → Σ = [500 30 ; 30 5]
  3. Eigen: λ₁ ≈ 501.8, w₁ ≈ (0.998, 0.06), about 3.5° instead of 45°. PC1 is now just "the x₁ column": it chases the big numbers.
  4. Fix: divide each column by its standard deviation. σ₁ = √500 = 22.4 (mm) or √5 = 2.24 (cm), σ₂ = √5. Either way you get the correlation matrix [1 0.6 ; 0.6 1], since 3/(2.24·2.24) = 30/(22.4·2.24) = 0.6.
  5. Its eigenvalues are 1 ± 0.6 = 1.6, 0.4 with w₁ = (1, 1)/√2, whatever the units.

(b) More features than points (N < D): the Gram trick

  1. 4 points with 5 features each, already centered (mean 0): x₁ = (0, 3, 0, 0, 4) x₂ = −x₁ x₃ = (2, 0, 1, 2, 0) x₄ = −x₃
  2. Normal way: eigen of X̃ᵀX̃, a 5×5 matrix. Trick: use K = X̃X̃ᵀ, only 4×4. Its entries are dot products of points: x₁·x₁ = 25, x₁·x₂ = −25, x₃·x₃ = 9, x₃·x₄ = −9, x₁·x₃ = 0 → K = [25 −25 0 0 ; −25 25 0 0 ; 0 0 9 −9 ; 0 0 −9 9]
  3. Eigen of K: the block [25 −25 ; −25 25] gives λ = 50 with u₁ = (1, −1, 0, 0)/√2; the other block gives λ = 18 with u₂ = (0, 0, 1, −1)/√2; the rest are 0. The 5×5 matrix has eigenvalues 50, 18, 0, 0, 0: same non-zero ones.
  4. Map back to 5-D: v = X̃ᵀu / √λ. v₁ = (x₁ − x₂)/√2 / √50 = 2x₁/10 = (0, 0.6, 0, 0, 0.8), and v₂ = x₃/3 = (0.67, 0, 0.33, 0.67, 0).
  5. Variances along them are λ/N = 50/4 = 12.5 and 18/4 = 4.5.

(c) SVD gives the same answer

  1. Use ①'s centered points. X̃ᵀX̃ = [20 12 ; 12 20] (that's 4Σ) → eigenvalues 32, 8 → singular values s = √32 = 5.66, √8 = 2.83.
  2. s²/N = 32/4, 8/4 = 8, 2: exactly λ₁, λ₂ from ①.
  3. V = the eigenvectors w₁ = (1, 1)/√2, w₂ = (1, −1)/√2.
  4. U = X̃V / s: column 1 = z / 5.66 = (−0.5, −0.5, 0.5, 0.5), column 2 = (−0.5, 0.5, −0.5, 0.5). So U·s = the scores z.

Say it in one sentence each: (a) PCA follows whichever feature has the biggest numbers, so standardize when units differ. (b) When N < D, eigen-decompose the small N×N matrix X̃X̃ᵀ and map back with v = X̃ᵀu/√λ. (c) X̃ = USVᵀ: V holds the directions, s²/N the eigenvalues, US the scores, with no Σ needed.

Choosing L when D = 4

After PCA on some 4-D data the sorted eigenvalues are λ = 5, 4, 0.6, 0.4 (total 10).

  1. Scree plot. Bars 5, 4, then a drop to 0.6, 0.4. The elbow is after the 2nd bar → L = 2.
  2. Fraction of variance explained F_L = (λ₁ + … + λ_L) / 10: F₁ = 50% F₂ = 90% F₃ = 96% F₄ = 100%. The 90% rule → L = 2.
  3. Reconstruction error = sum of the dropped eigenvalues: L=1: 4 + 0.6 + 0.4 = 5 L=2: 1.0 L=3: 0.4 L=4: 0. It only ever goes down, on test data too, so it has no minimum and can't choose L by itself.
  4. Profile likelihood. Split the eigenvalues at L into two groups, model each as Gaussian with its own mean and a shared σ². Because σ² = SS/D, ℓ(L) = −(D/2) ln(2πσ²) − D/2, so the best L is the split with the smallest within-group sum of squares SS:
    • L=1: {5} | {4, 0.6, 0.4}, means 5 and 1.67: SS = 0 + 2.33² + 1.07² + 1.27² = 8.19
    • L=2: {5, 4} | {0.6, 0.4}, means 4.5 and 0.5: SS = 0.25 + 0.25 + 0.01 + 0.01 = 0.52 ← smallest
    • L=3: {5, 4, 0.6} | {0.4}, means 3.2 and 0.4: SS = 3.24 + 0.64 + 6.76 + 0 = 10.64
    So ℓ = −7.11, −1.60, −7.63 → L = 2.

Say it in one sentence: sort the eigenvalues and look for where "signal" turns into "noise", either by eye (scree elbow), by a variance threshold (F_L ≥ 90%), or automatically (profile likelihood picks the split that makes both groups tightest); reconstruction error alone can't decide because it always falls.

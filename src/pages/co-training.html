Co-training: two models that teach each other

Sometimes each example comes with two views, x = (x1, x2), and each view is enough to classify it on its own: a web page's text and the text of links pointing to it, or an image and its caption. Co-training trains one model per view on the few labelled examples, then lets each model label the unlabelled points it is most sure about for the other model.

When does this work?

Two assumptions: each view alone is enough to classify (x1 or x2 separates the classes), and the views are conditionally independent given the class, p(x1, x2 | y) = p(x1 | y) p(x2 | y). The second is why a point A is sure of is a typical, informative example for B, rather than one B already finds easy.

Exam notes · 4-point version

Co-training, one round by hand

Data (x₁, x₂): labelled s₀ = (1, 6), y = 0 s₁ = (6, 7), y = 1; unlabelled u₁ = (0, 2) u₂ = (6.5, 10). The true boundary is 5 in both views. Model A sees only x₁, B only x₂; each predicts the nearer class mean, so its line sits halfway between the means. With only 4 points (2 labelled, 2 unlabelled), each model labels one point per round.

  1. Train on the labels. A: μ₀ = 1, μ₁ = 6 → t_A = 3.5. B: μ₀ = 6, μ₁ = 7 → t_B = 6.5. B's line is far from 5 because s₀ happens to have a high x₂.
  2. A labels for B. A's confidence is the distance from its line: |0 − 3.5| = 3.5 for u₁, |6.5 − 3.5| = 3 for u₂. Most confident: u₁ → class 0 (0 < 3.5). It goes into B's training set.
  3. B labels for A. The remaining point u₂ has x₂ = 10 > 6.5 → class 1. It goes into A's training set.
  4. Retrain. B: class-0 values 6, 2 → μ₀ = 4, so t_B = (4 + 7)/2 = 5.5 (was 6.5). A: class-1 values 6, 6.5 → μ₁ = 6.25, so t_A = (1 + 6.25)/2 = 3.625 (was 3.5). Both lines move toward 5.
  5. Why it worked. A picked u₁ only for its x₁. On B's axis it sits at x₂ = 2, a fresh, typical class-0 value that drags B's mean down. That needs the views to be conditionally independent: p(x₁, x₂ | y) = p(x₁ | y) p(x₂ | y).

Say it in one sentence: co-training trains one model per view on the few labels, and each model labels the unlabelled points it is most sure about for the other model; that helps because those points look like fresh examples in the other view.

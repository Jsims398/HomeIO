Boosting for any loss, and reading what the trees learned

Gradient boosting fits each new tree to the negative gradient of the loss, so one recipe works for any loss. XGBoost adds second derivatives and a penalty on tree size. Then two ways to look inside the finished model: feature importance and partial dependence.

①

Gradient boosting: fit each tree to the negative gradient

Each round, compute −∂ℓ/∂f at every training point (the pseudo-residual) and fit a tree to it. Only that gradient depends on the loss:

XGBoost: second-order steps and a price on every leaf

XGBoost minimises Σi ℓ(yi, f(xi)) + γJ + ½λ Σj wj², where J is the number of leaves and wj the leaf values. It uses both the gradient g and the second derivative h of the loss. Here: two-class data, log loss with π = σ(f), depth-2 trees.

Where w* and the gain come from

With ℓ(y, f + F) ≈ ℓ(y, f) + gF + ½hF², a leaf with value w costs Gw + ½(H + λ)w² + γ. The minimum is at w* = −G/(H + λ) and is worth −½G²/(H + λ) + γ. A split replaces one leaf by two, so it helps when gain = ½[GL²/(HL+λ) + GR²/(HR+λ) − G²/(H+λ)] is bigger than γ.

③

Feature importance

A model of 100 trees can't be read tree by tree. Instead, add up how much each feature's splits reduced the loss:

Rk(T) = Σj Gj I(vj = k),   Rk = (1/M) Σm Rk(Tm)

Sum over a tree's split nodes j: vj is the feature split on, Gj the loss reduction. Average over the M trees, then scale so the top feature is 100.

Data with a known answer: y = 2 sin(0.6 x1) + 0.3 x2 + 1·[x3 > 6] + noise, and x4 is pure noise.

④

Partial dependence plots

Importance says which features matter; partial dependence shows how. Fix feature k at a value, average the prediction over the other features in the training set:

f̄k(xk) = (1/N) Σn f(xk, xn,−k)

Topic 3 Murphy, PML — §3.2.2 Covariance reference

Distance, but measured in standard deviations

Euclidean distance treats every direction as equally surprising. Real data doesn't work that way: if height and weight are correlated, a point that's 2σ out along the correlation is unremarkable, and a point 2σ out perpendicular to it is a genuine outlier. Mahalanobis distance is the fix — it divides by the spread in whatever direction you're looking.

Reference

The covariance matrix, quickly

Σ = E[(x − μ)(x − μ)⊤]. Variances on the diagonal, covariances off it, and it's always symmetric and positive semi-definite — which is exactly the condition that lets you invert it and take its square root below.

Diagonal
σ²1, σ²2

Spread along each axis on its own. Set the off-diagonal to zero and Mahalanobis degrades into "divide each coordinate by its own σ" — standardized Euclidean.

Off-diagonal
Σ12 = Σ21

Tilt. Positive means the two rise together, negative means one falls as the other rises. This is what rotates the ellipse off the axes.

Correlation
ρ = Σ12 ⁄ σ1σ2

The same tilt, rescaled into [−1, 1] so it's comparable across units. |ρ| → 1 squashes the ellipse toward a line.

3.2.2

Mahalanobis distance

dM(x, μ)²  =  (x − μ)⊤ Σ−1 (x − μ)

Set it to a constant and you get an ellipse — which is precisely the level set of the Gaussian's exponent.

Move the point around. The cream rings are Euclidean distance from the centre — perfect circles, blind to the data. The terracotta rings are Mahalanobis at d = 1, 2, 3, stretched into the shape Σ describes. Two points on the same terracotta ring are equally surprising even though one is much farther away in plain distance.

It is Euclidean

Identity covariance means every direction has unit spread, so Σ−1 does nothing and the ellipses become the circles. Euclidean distance is the special case that assumes your features are uncorrelated and already standardized.

Units
Scale-free

Measure height in metres instead of centimetres and Euclidean distance changes; Mahalanobis doesn't. The Σ−1 soaks up the rescaling, which is why it works on features with mismatched units.

Where you'll see it
Gaussian exponent

The MVN density is proportional to exp(−½ dM²), so a contour of constant density is a contour of constant Mahalanobis distance. Also outlier scores, and the distance term in Gaussian discriminant analysis.

Worked example

"Equally surprising" — prove it

Suppose x₁ is a test score with σ₁ = 2 and x₂ is study hours with σ₂ = 1, uncorrelated, both centred at μ = 0. Two students sit at very different Euclidean distances from average. Which one is the stranger result?

Setup
Σ = [ 4  0 ; 0  1 ]  →  Σ−1 = [ 1⁄4  0 ; 0  1 ]
dM²(x) = x₁²⁄4  +  x₂²

A diagonal Σ inverts entrywise, so the quadratic form collapses to "each coordinate over its own variance."

Student A
x = (2, 0)
Euclidean: √(2² + 0²) = 2.00
dM² = 2²⁄4 + 0² = 1 + 0 = 1
dM = 1.00
Student B
x = (0, 1)
Euclidean: √(0² + 1²) = 1.00
dM² = 0²⁄4 + 1² = 0 + 1 = 1
dM = 1.00

A is twice as far in plain distance, yet both land on dM = 1 — the same terracotta ring. They're each exactly one standard deviation out, just along different axes. And "equally surprising" isn't a metaphor here; it's two equalities you can check.

1. Equal density

The MVN is p(x) ∝ exp(−½ dM²). Since dM² is the only place x enters, equal dM forces equal density: p(A) = p(B) ∝ e−0.5. A contour of constant Mahalanobis distance is a contour of constant probability density — the ellipse isn't a visual convention, it's the level set.

2. Equal tail probability

For a d-dimensional Gaussian, dM² follows a χ² distribution with d degrees of freedom. In 2D that has the tidy closed form P(dM > r) = e−r²⁄2. So the fraction of the population further out than A equals the fraction further out than B — both e−0.5 ≈ 61%. Being 1σ out in either direction is genuinely unremarkable.

d = 1 → 60.7% further out d = 2 → 13.5% d = 3 → 1.1%

Now add correlation — the mirror-image twist

Same trick in reverse. Let σ₁ = σ₂ = 1 with ρ = 0.8, and compare (1, 1) against (1, −1). Euclidean distance can't tell them apart — both are √2. Mahalanobis can.

Σ = [ 1  0.8 ; 0.8  1 ],  det Σ = 1 − 0.8² = 0.36
Σ−1 = (1⁄0.36) [ 1  −0.8 ; −0.8  1 ] = [ 2.78  −2.22 ; −2.22  2.78 ]
dM² = 2.78 x₁² − 4.44 x₁x₂ + 2.78 x₂²  ← the cross term is the new part
With the grain
x = (1, 1)
dM² = 2.78 − 4.44 + 2.78 = 1.11
dM = 1.05  ·  tail ≈ 57%
Both above average together — the cross term subtracts. Totally ordinary.
Against the grain
x = (1, −1)
dM² = 2.78 + 4.44 + 2.78 = 10.0
dM = 3.16  ·  tail ≈ 0.7%
High on one, low on the other, when they normally move together. The cross term adds. A real outlier.

Identical Euclidean distance, a 9× gap in dM², and one is ~80× rarer than the other. That factor lives entirely in the off-diagonal of Σ−1 — which is the whole argument for using it. Go back up to the plot, push ρ to 0.8, and drag the point between those two corners to watch the number swing.
